# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-03

### Added

- Initial project structure and core modules
- CLI interface with commands for scanning, backup, and validation
- Player name normalization and matching engine
- SQLite database for transfer history tracking
- Data protection system to preserve player attributes
- EDIT file handler (scaffolding for binary format)
- FotMob transfer source adapter (scaffolding)
- Comprehensive test suite for core functionality
- GitHub Actions workflows for fast scan, deep scan, and testing
- Full documentation and configuration guide
